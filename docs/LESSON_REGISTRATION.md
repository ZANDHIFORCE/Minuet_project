# 레슨 시간표 등록·검증·겹침 방지

[README](../README.md) · [화면 경로](ROUTES.md) · [검증 기록](VALIDATION.md)

## 입력과 시간 규칙

레슨 시간표는 매주 반복되는 요일·시작 시각·수업 길이입니다. 특정 날짜의 수업 기록인 `LessonInfo`와 구분합니다.

| 입력 | 규칙 |
| :--- | :--- |
| `teacherId` | 필수, 양의 정수, 등록된 강사 |
| `studentId` | 필수, 양의 정수, 등록된 학생 |
| `day` | 필수, 월요일=0부터 일요일=6까지 |
| `time` | 필수, 00:00~23:59의 분 단위 시작 시각 |
| `durationMinutes` | 필수, 1~1440분의 정수, 해당 요일의 24:00까지 종료 |

폼에는 수업 길이 60분을 기본으로 표시하지만 POST에서 길이를 생략하면 400입니다. `12:30`과 `12:30:00`은 같은 시각으로 취급합니다. 0이 아닌 초·나노초는 거부합니다.

자정을 넘는 수업은 등록할 수 없습니다. 23:30부터 30분은 허용하고 종료를 `24:00`으로 표시하지만, 31분은 거부합니다. 종료 시각을 다음 요일로 자동 이월하지 않습니다.

## 겹침 판정

같은 요일에 강사 또는 학생이 같고, 다음 두 조건을 모두 만족하면 충돌합니다.

```text
기존 시작 < 새 종료
새 시작 < 기존 종료
```

종료 시각에 바로 다음 수업을 시작하는 것은 허용합니다.

| 기존 수업 | 새 수업 | 같은 강사 또는 학생인 경우 |
| :--- | :--- | :--- |
| 13:00~14:00 | 13:30~14:30 | 충돌 |
| 13:00~14:00 | 12:30~13:15 | 충돌 |
| 13:00~14:00 | 13:15~13:30 | 충돌 |
| 13:00~14:00 | 12:00~15:00 | 충돌 |
| 13:00~14:00 | 14:00~14:30 | 허용 |

요일이 다르거나 강사와 학생이 모두 다르면 같은 시간 구간도 허용합니다. 수정 시에는 자기 자신을 제외하고 검사하며 수업 길이만 늘리는 경우에도 적용합니다.

## 동시 등록과 수정

시작 시각의 유일성 제약만으로는 13:00과 13:30에 시작하는 겹친 수업을 막을 수 없습니다. JDBC 저장소는 다음 과정을 **하나의 READ_COMMITTED 트랜잭션**으로 실행합니다.

1. 대상 강사 행, 대상 학생 행을 차례로 `SELECT ... FOR UPDATE`로 잠급니다.
2. 잠금을 얻은 뒤 최신 저장 구간을 조회해 겹침을 검사합니다.
3. 충돌이 없으면 등록 또는 수정하고 트랜잭션을 종료합니다.

같은 강사·학생을 공유하는 요청은 잠금에서 대기한 뒤 앞 요청의 결과를 확인합니다. 겹치는 요청 둘이 동시에 통과하지 않도록 검사와 저장 사이에 잠금을 유지합니다. 수정·등록이 동시에 실행될 때도 같은 순서를 사용합니다. 기존의 시작 시각 유일성 제약은 추가 방어로 유지합니다.

이 보장은 같은 DB에 대해 이 저장소의 쓰기 경로를 사용하는 경우의 동작입니다. 임의의 SQL로 시간표를 직접 저장하면서 잠금·겹침 검사를 생략하는 경우까지 막는 DB 트리거를 구현한 것은 아닙니다.

메모리 구현은 한 인스턴스에서 동기화한 검사·저장과 객체 복사로 같은 구간 규칙을 적용합니다. 과거 5개 인자의 생성자와 수업 길이가 없는 기존 JSON은 60분으로 취급합니다. 기존 영속 DB 스키마·충돌 데이터의 마이그레이션은 제공하지 않습니다.

## 화면과 HTTP

`GET /LessonSlot/new`에서 등록하고 `GET /LessonSlot/list`에서 시작·종료·수업 길이를 확인합니다.

| POST 결과 | 상태 | 동작 |
| :--- | :--- | :--- |
| 성공 | 302 | 목록으로 이동, 성공 안내 |
| 누락·형식·범위·없는 강사/학생·자정 초과 | 400 | 입력 폼에 필드별 안내 |
| 강사 또는 학생의 시간 겹침 | 409 | 입력 폼에 충돌 안내 |

오류 시 표현 가능한 입력값과 선택을 유지합니다. 등록 필드 다섯 개만 바인딩하므로 임의 `id`를 보내 기존 레슨을 덮어쓸 수 없습니다. DB 예외 문자열은 사용자에게 출력하지 않습니다.
